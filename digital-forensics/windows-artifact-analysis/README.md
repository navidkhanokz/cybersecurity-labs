# Windows Artifact Analysis

## Overview

This project documents a practical digital forensics lab focused on the identification and analysis of Windows forensic artifacts.

The objective is to understand how commonly available Windows artifacts can provide information about system activity, user behavior, and potentially relevant evidence during a forensic investigation.

> **Lab Type:** Training / Practical Digital Forensics Lab
> **Focus:** Windows Forensics & Artifact Analysis

---

## Objectives

* Understand the role of Windows forensic artifacts.
* Identify commonly examined Windows artifacts.
* Analyze artifacts for evidence of user and system activity.
* Practice documenting forensic findings.
* Develop a structured digital investigation workflow.

---

## Tools

* WinHex
* Windows built-in forensic utilities
* File Explorer
* Command Prompt / PowerShell
* Other forensic tools as applicable

---

## Investigation Methodology

The investigation follows a basic digital forensic workflow:

1. Evidence identification
2. Evidence preservation
3. Artifact examination
4. Data analysis
5. Finding correlation
6. Documentation
7. Conclusion

---

## Windows Artifacts Examined

The lab focuses on artifacts such as:

* Windows Registry
* Event Logs
* Prefetch files
* File system metadata
* User activity artifacts
* Recently accessed files
* Browser-related artifacts
* Recycle Bin information
